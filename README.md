# α7 IV × WD Blue 8TB — 高校生の将来性と現実的な活用法

PDF「高校生がSony α7 IVとWD Blue 8TBを活用する将来性と現実的な活用法」の全文（5章＋出典37件）を、インタラクティブな3D Webサイトにしたものです。

## 特徴
- **Three.js 3Dシーン（すべてコードで生成）**: α7 IV（レンズ脱着→センサー表示、バリアングル液晶の展開）、WD Blue 8TBの分解ビュー（プラッタ、CMRトラック、アクチュエータ）、3-2-1バックアップのネットワーク、写真ギャラリーの渦、未来へのワープトンネル
- **パーティクルモーフィング**: 8,000粒子が「α7 IV」→絞り羽根→「8TB」→「3-2-1」→「すごい！」→球体→「好きこそ物の上手なれ」と変形
- **ポストエフェクト**: Bloom、色収差（スクロール速度に連動）、シャッターフラッシュ、FBMシェーダーの星雲背景
- **アニメーション**: GSAP ScrollTrigger + Lenisの慣性スクロール、文字分割アニメーション、カウンター、3Dチルトカード、マグネティックボタン、ビューファインダー風HUD
- **出典**: 本文中の番号 [n] にホバーすると出典が表示され、クリックすると出典一覧へ移動
- 描画性能に合わせてピクセル比を自動調整

## 開発
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/
```
